# runbook 外部仕様書

本ディレクトリは、Markdown 手順書自動実行フレームワーク **runbook**(v0.4.0)の外部仕様を、
**この仕様書のみから同等のアプリケーションを再実装できるレベル**で記述したものである。
内部実装(モジュール構成・関数名など)には立ち入らず、外部から観測可能な振る舞い
(入力形式・コマンド体系・画面出力・ログ成果物・終了コード・エラー条件)のみを定義する。

## 構成

| ドキュメント | 内容 |
|---|---|
| [01_overview.md](01_overview.md) | 目的、設計原則、動作環境、全体像、用語定義 |
| [02_runbook_format.md](02_runbook_format.md) | 手順書 Markdown ファイルの書式仕様(共通設定・ステップ・変数・ansible/playbook) |
| [03_criteria.md](03_criteria.md) | 正常性基準式(RB-EXPECTED)の言語仕様と評価規則 |
| [04_cli.md](04_cli.md) | CLI 仕様(サブコマンド・オプション・対話フロー・終了コード) |
| [05_execution_logging.md](05_execution_logging.md) | 実行モデル(コマンド実行・判定・中断・マスキング)とログ成果物の仕様 |
| [06_examples.md](06_examples.md) | 実際の実行出力例(採取日 2026-08-31) |

## 仕様の優先順位

本仕様書間に矛盾がある場合、より詳細に規定している方(通常は 02〜05 の各論)を正とする。
06 は実機採取した参考出力であり、表示の細部(色・桁位置)は規範ではない。

## 対象バージョン

- runbook v0.4.0(2026-07-04 時点の実装)
- Python 3.10 以上 / 依存: PyYAML >= 6.0, rich >= 13.0
