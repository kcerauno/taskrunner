# 01. 概要

## 1. 目的

runbook は、従来 Excel で管理されていた作業手順書を **Markdown ファイル**に置き換え、
そこに書かれたコマンドを**上から順に実行し、各ステップの正常性を機械判定し、
証跡(エビデンス)ログを自動保存する** CLI ツールである。

- 手順書は一般的な Markdown としてそのままプレビュー・レビューできる(専用ビューア不要)。
- 実行時は各ステップのコマンドをローカルの bash で実行し、
  「終了コード + 出力への正規表現マッチ」を論理式で組み合わせた**正常性基準**で合否判定する。
- 1 回の実行ごとにログディレクトリを作成し、人間可読ログ(run.log)・機械可読サマリ
  (result.json)・各ステップの生出力を保存する。

## 2. 設計原則(仕様判断の基準)

本ツールの仕様は次の原則に基づく。機能追加・変更の際もこの原則との整合を判断基準とする。

1. **「機械は実行と判定を担うが、継続の決定は常に人間が担う」**
   - ステップが失敗したら**常に即中断**する。自動リトライ・自動スキップ・自動継続はしない。
   - 切り戻し(ロールバック)も自動実行せず、実行コマンドを**案内するだけ**。
   - 手動ステップの完了確認は Enter 空打ちでは通らず、`y` の明示入力を要求する。
2. **fail-loud(黙って無視しない)**
   - 「書いたのに効かない」状態を作らない。設定の置き場所間違い・未定義変数・
     不明なキー/セクション名はすべて**パースエラー**にする。
   - ansible のインベントリに共通デフォルトを持たせない(指定漏れが「意図しない環境での
     実行」ではなく「エラー」になるようにする)。
3. **新しい記法を増やさない**
   - エスケープ記法・命名規則(プレフィックス等)・独自 DSL の追加を避け、
     Markdown / YAML / Python 風論理式 / ansible の既存記法の組み合わせで構成する。
4. **ターミナル出力はテキストログとして保存可能な形式**
   - 囲み罫線パネルを使わない行ベース出力。長い行の強制折り返しをしない
     (`tee` 等でファイル保存しても行が崩れない)。

## 3. 動作環境・配布形態

| 項目 | 内容 |
|---|---|
| 実行環境 | Linux(bash が `/bin/bash` にあること)。実行先は**ローカルのみ**(SSH 実行機能はない) |
| Python | 3.10 以上 |
| 依存ライブラリ | PyYAML >= 6.0(YAML 解釈)、rich >= 13.0(ターミナル表示) |
| パッケージ名 | `runbook` |
| 起動方法 | コンソールスクリプト `runbook`(および `python -m runbook`) |
| ansible 連携 | ansible / ansible-playbook コマンドを**ローカルコマンドとして**組み立てて起動するラッパー。ansible 自体は同一環境(例: 同じ venv)に導入済みで PATH にある前提 |

`--version` は `runbook 0.4.0` の形式でバージョンを表示する。

## 4. 全体像

```
手順書.md ──▶ runbook check   … 書式・基準式・参照パスの静的検証(実行しない)
          ──▶ runbook list    … ステップ一覧表示
          ──▶ runbook renumber… ## 見出しへの連番付与(ファイル書き換え)
          ──▶ runbook run     … 実行
                 │
                 ├ 実行前サマリー表示 → y 確認ゲート(--yes で省略)
                 ├ 作業者名(必須)・確認者名(任意)の記録
                 ├ 各ステップ: コマンド実行(bash -c)→ 正常性基準で判定
                 │    OK → 次のステップへ / NG・エラー → 即中断(RB-ONFAIL 表示)
                 └ logs/<手順書名>_<日時>/ に run.log・result.json・生出力を保存
```

## 5. 用語定義

| 用語 | 定義 |
|---|---|
| 手順書 | runbook が実行する UTF-8 の Markdown ファイル |
| 共通設定 | 手順書前書きの ` ```runbook ` フェンスに YAML で書く手順書全体の設定(title / vars / share_env / ansible / secrets) |
| ステップ | `## ` 見出し 1 つに対応する実行単位。記載順に 1 から番号が付く |
| セクション | ステップ内の `### RB-*` 見出しで区切られた要素(RB-DESCRIPTION / RB-CMD / RB-EXPECTED / RB-LOCALDEF / RB-ONFAIL) |
| ランナー | ステップの実行方式。`shell`(bash)/ `ansible`(ad-hoc, shell モジュール)/ `playbook`(ansible-playbook)/ `manual`(手動ステップ)の 4 種 |
| 手動ステップ | RB-CMD を持たないステップ。コマンド実行の代わりに作業者の完了確認(`y` 入力)を待つ |
| 正常性基準 | RB-EXPECTED に書く論理式。終了コード・標準出力・標準エラーから合否を判定する。省略時は `rc == 0` |
| 切り戻しセクション | `# RB-ROLLBACK` 見出し以降のステップ群。`run --rollback` でのみ実行される |
| 実行前サマリー | run 開始前に表示される確認情報(対象ステップ・変数・使用インベントリ等)と `y` 入力ゲート |
| 作業者 / 確認者 | 実行時に記録する担当者名。作業者は必須、確認者は任意 |
| シークレット | 共通設定 `secrets:` に宣言した変数。値が表示・ログで `*****` にマスクされる |
| ログディレクトリ | 実行 1 回ごとに作成される証跡保存先 `logs/<手順書名>_<日時>/` |
